# UIUX_Frontend_Task_Akshita_Chahal
A project to depict my UI/UX and frontennd skills.


A modern, responsive redesign of the **DroneTV** digital ecosystem, created as part of the **UI/UX Designer & Frontend Developer Internship Practical Assignment** for IPAGE Group.

The project translates a Figma-based UI/UX concept into a responsive multi-page frontend using HTML5, CSS3, and vanilla JavaScript.

---

## Overview

The redesign presents DroneTV as a connected platform for exploring drone technology, industry services, professional training, and user resources.

The website includes the following screens:

* Home / Ecosystem
* Services
* Courses & Training
* Login
* User Dashboard

The design combines a dark technology-focused visual language with clean light sections and electric-blue accents to create a modern and professional interface.

## Pages

### Home / Ecosystem

The landing page introduces the DroneTV ecosystem with:

* Hero section
* Primary calls to action
* Industry statistics
* Drone technology categories
* Industry analysis and content
* Verified industry innovators
* Certified service providers
* Industry events
* Final CTA
* Footer

### Services

The Services page presents DroneTV's aerial and drone-related service ecosystem through structured service categories, capabilities, and supporting content.

### Courses & Training

The Courses & Training page presents professional learning and certification opportunities for users interested in developing skills within the drone industry.

### Login

A dedicated authentication interface designed to provide users with access to the DroneTV ecosystem.

### User Dashboard

A product-style dashboard designed to give authenticated users an overview of their courses, saved content, companies, events, certifications, activity, and account-related sections.

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Akshiitachahal/UIUX_Frontend_Task_Akshita_Chahal
```

### Navigate to the project

```bash
cd UIUX_Frontend_Task_Akshita_Chahal
```

### Run the project

Open `index.html` directly in a browser, or use the **Live Server** extension in Visual Studio Code for local development.

No backend setup or database configuration is required.
